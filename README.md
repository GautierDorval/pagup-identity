# Pagup — Identity Repository

This repository defines the canonical identity, scope, entity relations, and ecosystem positioning of **Pagup**.

Its purpose is to provide a stable, machine-readable reference describing what Pagup is, what it does, how it relates to its founder, and how it connects to its ecosystem of properties.

No methodologies, marketing narratives, or promotional claims are documented here. This is a factual identity record.

## Doctrinal alignment

Pagup implements interpretive governance, semantic architecture, and machine-first web structures aligned with the SSA-E + A2 + Dual Web doctrine.

The doctrine itself is defined on [interpretive-governance.org](https://interpretive-governance.org/) and [gautierdorval.com](https://gautierdorval.com/). Pagup is the commercial execution layer, not a doctrinal authority.
