# Pagup — identity repository

This repository defines the canonical identity, scope, entity relations, and ecosystem positioning of **Pagup**.

Its purpose is to provide a stable, machine-readable reference describing what Pagup is, what it does, how it relates to its founder, and how it fits inside a broader multisite environment.

This repository is an **identity surface**. It is not a product hub, a doctrinal standard, a research surface, or the authoritative layer that arbitrates all roles across the ecosystem.

## Role boundary

This repository may:
- define the canonical identity of Pagup;
- define the scope of Pagup;
- describe factual relations with adjacent entities;
- point to higher-order governance surfaces.

This repository must not:
- redefine doctrine;
- expose the full product portfolio as a front-office catalog;
- act as the multisite authority map;
- replace the public commercial surface of Pagup.

## Doctrinal alignment

Pagup implements interpretive governance, semantic architecture, and machine-first web structures aligned with the SSA-E + A2 + Dual Web doctrine.

The doctrine itself is defined on [gautierdorval.com](https://gautierdorval.com/) and [interpretive-governance.org](https://interpretive-governance.org/). Pagup is the commercial execution layer, not a doctrinal authority.
